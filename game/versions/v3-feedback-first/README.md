# V3: Feedback-First Random Short Episodes

Snapshot taken on 2026-09-09 after the interaction pass.

- The resource bars are the primary feedback: changed bars flash by direction and
  visibly animate to the new position.
- The result area keeps only the original one-line black explanation.
- A small drag stays in the neutral position and springs back; only a clear
  left/right swipe commits a choice.
- The top-right counter uses plain language (`还剩 N 次`) instead of the internal
  board-review wording.
- The deck contains randomized daily cards, short market/team episodes, explicit
  legacy callbacks, rescue cards, and review endings.

`玩.html` is self-contained and can be opened directly. The other files are the
source snapshot used to generate it.
