# 《别叫我老板》：六点半灯具厂

## 要治的病

用户说的是没有欲望、没有意外、没有可感知的因果，不是看不懂字。
参考文档中的解决方案是讨论材料，不是逐条执行的任务单。本分叉不覆盖根目录 V3、startup 草稿或线上页面。

## 三条路与取舍

1. 只重写现有日常：成本最低，但仍然是别人递问题，不选。
2. 多行业创始人：开局很主动，但大量通用卡会让餐厅和软件公司说同一种话，暂不选。
3. 一个具体产品、两种初衷、一个会记住你的行业：选这一条。深度先于行业数量。

## 故事

你和阿岑在榕树路租下半间修理铺，开了「六点半」。你们做桌灯。
第一张卡不是危机，而是决定它为什么存在：到点催人回家，或替晚归的人留一盏灯。
罗姐负责把怪念头做成实物，周野负责把它说给世界听，孟女士带着一张能解救你也能买走你的支票。
隔壁修理铺的老唐先借你工具，后来可能成了对手。猫叫董事长，但没有投票权。

主题不是「商业太残酷」，而是「你造的东西，会不会把你变成你讨厌的人」。
同样允许另一种答案：把它卖掉、做小、妥协，都不自动等于失败。

## 一局的情绪，不是固定剧情

- 18 次决定，以创作、表达、关系、押注、兑现、喘息混排。结算不是第 19 道试题。
- 起步先做出东西、见到第一个人；风在第 5–7 次决定间到来，持续 4–5 次；末段退潮。
- 风口有真实成功画面和连胜机会，不只把资源条刷绿。只放大外部生意，不放大人的感情。
- 小剧集保留「占位 + 分支 + 权重差」，不使用强制跳转。结局前给已接受的承诺兑现空间。
- 一局有必达的创始人决定和随机岔路；不是所有人按同一时间表被同一人背叛。

## 对参考方案的两处反对

- 不把合理决定统一扣心、任性统一加心。道歉、守约、给员工自由，也可以是你的偏执。
- 钱多与伙伴信任不是犯罪。钱、人上沿只是充足，不强行下台；客满需要管理交付，心满需要有人叫停。
  钱、人、客、心归零仍可能结束；客、心爆表触发对应后果。危险前先给一次明确补救，不能靠风口倍率突然判死。

## 每次选择必须发生的事

1. 双方是不同动作，不是「接受 / 拒绝」；有一批零数值的表达型选择。
2. 有一句立即可见的结果，不限时强制跳走，玩家读完再继续。
3. 关键决定改变后续卡或结局，而不仅变成屏幕上一枚状态徽章。
4. 灯、纸箱、旧照片等物件会留下来；回声必须明确说出是你当年做了什么。
5. 遇到的难题有时能赢、有时值得笑、有时只需要选自己喜欢的那个。

## 交付与验收

可双击的独立玩.html、可编辑的故事源、22 列 cards.csv、完整故事手册、确定性模拟与真人视角试玩记录。
旧版内容不动，不推送、不替换线上版本。只新增本分叉并更新版本索引。
验证两条产品承诺、押注成功与失败、不同关系结局、跨局回声、刷新续玩、窄屏与键盘/触摸交互。
用数据查漏，不把「99.8% 走完」误认成「好玩」。审稿重点是表达选择比例、明确后果、重复率与截图时刻。
