# GPT 6 Astra 作品：实现与验收

## 文件分工

- story.py：78 张卡、分支条件、资源变化、角色反馈和 9 个结局的唯一故事源。
- logic.js：浏览器和模拟共用的确定性状态机；v8 版本隔离旧故事，保留无限任期、冷却、资源归零救援、峰值缓冲和坏存档校验。
- engine.js / index.html：原版 UI 和拖动实现；标题、开始页及元数据写入 GPT 6 Astra 作品标记。
- build.py：22 列、状态读写、结局可拒绝、阅读预算校验；--publish 生成独立 GitHub Pages 文件。
- verify.test.js / test_build.py：16 项 Node 测试与 3 项 Python 测试。

## 剧情验证

开场收购两选、产能/法务回访、价格战两选和新品押注均有真实卡池回访；错误分支不出现，主线收束不强制结束经营。

验证产品押注成功/失败均可能、旧团队回援只在此前公平付薪后出现、资源归零后救援只触发一次、峰值有缓冲卡、离职合伙人不继续以在职角色出现，以及新存档命名空间不删除旧进度。
