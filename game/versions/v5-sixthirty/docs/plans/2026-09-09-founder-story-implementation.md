# GPT 6 Astra 作品：实现与验收

## 文件分工

- story.py：90 张卡、分支条件、资源变化、角色反馈和 9 个结局的唯一故事源。
- logic.js：浏览器和模拟共用的确定性状态机；v7 版本隔离旧故事，保留无限任期、冷却、救险和坏存档校验。
- engine.js / index.html：原版 UI 和拖动实现；标题、开始页及元数据写入 GPT 6 Astra 作品标记。
- build.py：22 列、状态读写、结局可拒绝、阅读预算校验；--publish 生成独立 GitHub Pages 文件。
- verify.test.js / test_build.py：14 项 Node 测试与 3 项 Python 测试。

## 剧情验证

开场两选、丑闻两选、机器人职位两选、职位后续两选，共 16 条组合，全部在真实卡池中走到对应回访。错误分支不出现，主线收束不强制结束经营。

验证开会机器人赌成功/失败均可能、返聘样机确实回来、假订单解决后清除旧债、离职合伙人不继续以在职角色出现，以及新存档命名空间不删除旧进度。
