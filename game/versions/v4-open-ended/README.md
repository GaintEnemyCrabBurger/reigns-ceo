# V4: Open-Ended Tenure

Snapshot taken on 2026-09-09 after the open-tenure pass.

- The top-right meta now shows elapsed tenure (`在任 X 个月 / X 年`), not a countdown.
- There is no fixed review turn. A run continues until a resource reaches 0/100 or a
  future card explicitly triggers an ending.
- One-time cards are recycled when the random pool is empty, so a healthy company can
  keep receiving decisions indefinitely.
- Consequences and counters remain available inside the current run. `再来一局`
  always starts from the initial resources with an empty flag set.
- The default deck contains 136 cards and eight resource endings. The old V3 review
  endings remain available in `../v3-feedback-first/` for comparison.

`玩.html` is self-contained and can be opened directly. The other files are the source
snapshot used to generate it.
