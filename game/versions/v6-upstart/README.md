# 《上位》独立版

《上位》是基于原版 Reigns CEO 框架制作的独立剧本版本。玩家从曜石云的实习生开始，在约 22 次决定内冲到 CEO；真正的游戏从坐上椅子后开始。

## 运行

直接打开 `玩.html` 即可试玩。若浏览器限制本地脚本，可在仓库根目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 内容结构

- 89 张卡：31 张强制主线卡、42 张 CEO 开放卡、16 张结局卡。CEO 开放池至少运行 7 次后才会进入收购、交棒或清算类终局。
- 四条可见资源槽：现金、人心、业绩、权力；任意资源归零或爆表立即结束本局。
- 资源边界优先于剧情标记：一张牌同时触发资源边界和剧情结局时，先结算资源结局；四条槽都安全时才进入剧情结局。
- 两条隐藏计数器：风险与证据。灰色选择提高风险，留痕、录音和账本提高证据；后续审计、媒体和董事会会回访它们。
- 结局由玩家在调查、清账、黑账、交接等终局卡上明确选择，不靠随机权重替玩家决定；资源触底/爆表始终立即结束本局。
- 故事手册对剧情结局列出实际入口卡、选择方向和入口条件；资源结局列出资源边界，和运行时结算保持一致。

## 维护

修改 `story.py` 后运行：

```powershell
python -X utf8 story.py
python -X utf8 build.py
python -X utf8 -m unittest -v test_story.py
```

`index.html` 和 `玩.html` 是内容相同的自包含发布文件，`source-index.html` 是页面源码模板；`cards.csv`、`story-meta.json` 和 `故事手册.md` 是由源剧本导出的产物。`build.py` 会在生成后检查它们一致。
