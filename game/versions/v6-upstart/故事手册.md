# 《上位》完整故事手册

从实习生开始，左右每一次都不是善恶题，而是上位速度与后果的交换。

## 资源

现金、团队、市场、资本四条槽仍为 0–100。资源触底或爆表优先于剧情结局标记；风险和证据藏在卡牌后果里。

## act1

### intern_open

**财务部主管 周启明**

八万元市场费报销单，差一个签字。  
主管把笔推给你：今晚把它变成花掉的钱。

- ← **上交审计**：你把单据放进审计邮箱。下午，主管第一次叫你全名。
- → **先平账，留副本**：你把发票拆成三张。现金到账，副本留在你的云盘里。

触发：`turn=1`

### intern_audit

**审计专员 林岚**

匿名邮箱里只有一张单据。审计问：你愿不愿意留下名字？

- ← **实名提交**：你签了名。主管没有被立刻开掉，但你的试用期被立刻延长。
- → **匿名就好**：审计收下了证据。你没出名，却多了一张能回头的牌。

触发：`无`

### intern_audit_result

**财务部主管 周启明**

主管被叫去喝茶，回来后只问了一句：是不是你？

- ← **看着他说是**：你没有躲。人事部把你调去最缺人的项目组。
- → **装没看见**：你低头整理文件。主管笑了，记住了你的沉默。

触发：`无`

### intern_fix

**财务部主管 周启明**

主管把第二张发票递回来：咨询费写高一点，差额算你的辛苦费。

- ← **改成咨询费**：你的工资还没涨，银行卡先多了八千。
- → **让他自己签**：你把笔推回去。主管没骂你，只把你的名字从会议名单删掉。

触发：`无`

### intern_gift

**财务部主管 周启明**

项目过了。主管要你用部门卡买一块表，今晚送到他家。

- ← **刷部门卡**：表送到了。你的转正通知也送到了。
- → **发票走私人**：你替他垫了钱。主管说以后会还，像所有不准备还的钱一样。

触发：`无`

### intern_promotion

**人事经理**

正式员工名额只有一个。你的项目报告里，三个人都写了自己。

- ← **把功劳写给团队**：你拿到正式编制。工程师许棠把你的名字写进了项目群公告。
- → **把救火写成我的**：你升得更快。许棠在茶水间学会了不再叫你的名字。

触发：`无`

## act2

### manager_team

**工程师 许棠**

你刚拿到正式编制，许棠把一份真实的故障清单放到你桌上：  
‘你要带我们赢，还是只要看起来赢？’

- ← **把他放进核心群**：你把故障清单原样发给客户。许棠第一次在会上替你说话。
- → **先把数字做漂亮**：你删掉三条红色告警。周启明给你一张新名片：项目负责人。

触发：`无`

### manager_power

**事业部副总 周启明**

周启明没有祝贺你，只把一把客户会议室的钥匙推过来：  
‘替我拿下这个客户，你的名字就能继续往上写。’

- ← **要书面授权**：你让他把承诺写进邮件。第一次，你的晋升速度换成了可追溯的权力。
- → **先替他扛下来**：你接过钥匙，也接过他的债。周启明在通讯录里给你改了备注：自己人。

触发：`无`

### manager_team_review

**项目经理 许棠**

许棠把客户的追问转给你：他们要的不是漂亮数字，而是明天还能不能上线。

- ← **让他当面解释**：许棠把真实故障讲清楚。客户留下，团队也知道你不会把人藏到报告后面。
- → **替他讲成路线图**：你把故障改名成路线图。许棠没有反驳，只把原版留在自己的硬盘里。

触发：`无`

### manager_power_review

**事业部副总 周启明**

周启明把客户会议留给你，却没有把承诺写进授权书：  
‘你先做出结果，手续总会补。’

- ← **把客户拉进邮件**：你让客户成为见证人。周启明不高兴，但再也不能说这只是你的个人承诺。
- → **先替他签字**：你用自己的名字填上空白。周启明的承诺变成你的债，职位也提前升了一格。

触发：`无`

### manager_day1

**事业部副总**

你刚接手曜石云的连锁客户项目。吴老板把回扣比例写在报价单背面：拿不拿，今晚就知道。

- ← **按规则招标**：报价贵了一点，但流程干净。周启明说你还不懂生意。
- → **收回扣，分给组里**：预算像魔术一样变多。每个人的账户里都有了同一个秘密。

触发：`无`

### manager_clean_bid

**采购负责人 吴老板**

你拒绝了回扣，吴老板把一份更贵的合规报价放在桌上：  
‘你们公司真准备按规则活？’

- ← **签合规报价**：项目成本上升，客户却愿意把长期合同给你。干净不是便宜，是可续约。
- → **换一家供应商**：你保住流程，也失去一周时间。周启明说：你把机会让给了别人。

触发：`无`

### manager_dirty_bid

**采购负责人 吴老板**

回扣已经进了账。吴老板又发来一条消息：  
‘这次只要你签，下一次我让你自己挑供应商。’

- ← **把钱分给项目组**：每个人都拿到一笔‘项目奖金’。大家笑着收下，笑容里多了一份共同责任。
- → **钱只进自己的口袋**：你把差额转进私人账户。现金更厚，许棠却把会议录音存进了云端。

触发：`无`

### manager_leader

**事业部副总**

周启明约你去会所谈项目。买单的人，通常也决定谁升职。

- ← **我来买单**：他拍着你的肩说放心。那一晚的账单比你的年薪还高。
- → **把客户请来**：你让客户坐主位。周启明不高兴，但合同第二天盖了章。

触发：`无`

### manager_crisis

**项目总监**

演示前夜，核心工程师崩溃了。明早十点，客户要看一个不存在的功能。

- ← **把事故写成延期**：你让客户看到真实进度。项目没丢，但副总说你没有狼性。
- → **把锅甩给供应商**：演示按时开始。供应商收到律师函，客户收到你的晋升推荐。

触发：`无`

### manager_report

**事业部副总**

季度报告里，你的增长数字被副总改成了他的。  
他问：要功劳，还是要位置？

- ← **公开争回来**：你保住名字，差点失去项目。团队第一次觉得你不是软柿子。
- → **换一个总监位置**：你的名字从报告消失，职位从项目经理变成了总监候选人。

触发：`无`

### manager_promotion

**人事经理**

副总把一个必败项目塞给你：做成，直接进总监名单；做不成，正好有人负责。

- ← **接下这个烂摊子**：你把失败概率写在纸上，然后签了名。人事部把你列进总监候选。
- → **先要资源再接**：你逼周启明把预算和人写进邮件。你慢了一步，但没有把命交出去。

触发：`无`

## act3

### director_budget

**董事会秘书**

董事会要下季度增长百分之四十。账上没有钱，市场却已经在等。

- ← **砍掉三个项目**：数字不会漂亮，但现金活了。韩董事长把你的名字写进了‘能收拾残局’名单。
- → **先做出增长再说**：你把未签的订单写成意向。投资人欢呼，证据也一起长出来。

触发：`无`

### director_deputy

**猎头**

总监位置给你配一个副手。一个忠诚但普通，一个能干但知道太多。

- ← **提拔老同事**：你把许棠放进核心群。他不会抢你的椅子，但会记住你给过他的名字。
- → **挖那个能干的**：你把顾惟挖来。他把客户和数字一起带来，也把一份备用组织架构带来。

触发：`无`

### director_leader

**前任副总**

周启明被调查了。他私下发来一条消息：‘你要是说实话，我也只能说实话。’

- ← **替他挡一次**：他把董事会的票带给你。你们的名字从此写在同一页。
- → **把证据交上去**：周启明被带走。韩董事长夸你勇敢，也开始检查你的抽屉。

触发：`无`

### director_audit_clean

**审计负责人 林岚**

审计翻到了那张八万元报销单。  
她没问你是不是英雄，只问：证据要不要留下？

- ← **把证据交全**：你把原始邮件、付款记录和自己的签字一并交出。林岚写下：可整改。
- → **只交纸面材料**：你没有撒谎，却只给了她能看见的一半。林岚把缺口标成黄色。

触发：`无`

### director_audit_dirty

**审计负责人 林岚**

审计翻到了那张八万元报销单。  
她把回扣名单推到你面前：现在补钱，还是让名单继续往上走？

- ← **补回自己的那份**：你把钱退回，却没有供出分到奖金的人。林岚说：这不是结案，是第一行。
- → **把文件烧掉**：纸没了，扫描件还在。林岚把复印件夹进董事会材料。

触发：`无`

### director_clean_reckoning

**审计负责人 林岚**

林岚把整改建议分成两栏：公开，或者只给董事会看。  
‘你以后每一次增长，都要从这张表开始。’

- ← **公开整改表**：你让所有部门都看见缺口。速度慢了一点，但没人需要替你猜答案。
- → **先稳住董事会**：你把整改藏在董事会材料里。林岚点头，却把副本发给独立董事。

触发：`无`

### director_dirty_reckoning

**审计负责人 林岚**

林岚没有把你交上去，只问一个名字：回扣名单里，谁最先找你？  
你知道她是在给你最后一次选择。

- ← **把周启明写上去**：你交出上级的名字。林岚收下材料，周启明开始给董事会打电话。
- → **把自己写上去**：你把责任压在自己身上。林岚说：这会让你升得快，也会让你掉得重。

触发：`无`

### director_media

**财经记者**

唐记者拿着一份采购邮件找你：给一个回应，我可以等；不回应，明早全网都是曜石云。

- ← **买下这个版面**：新闻没发。唐记者收下采访费时说，下一次问题会更具体。
- → **让他发**：你的名字上了热搜。董事会没解雇你，因为股价先涨了。

触发：`无`

### director_board

**董事长**

董事会要一个代理 CEO。董事长说：‘你可以带公司上去，也可以替所有人下去。’

- ← **接受，但公开旧账**：韩董事长把任命书推过来。台下鼓掌，台上的人开始删聊天记录。
- → **拿旧账换授权**：你把证据摊在桌上，换到预算、人事和一间更大的办公室。

触发：`无`

## act4

### acting_ceo

**董事长**

你只有两周时间处理旧账。董事长给你两把钥匙：清算，或者继续利用。

- ← **清掉所有灰账**：你让林岚逐笔补账。现金像血一样流出去，但公司终于能被审计。
- → **先把公司做大**：你把旧账压进并购协议。估值翻倍，风险也翻倍。

触发：`无`

### acting_crisis

**警方经侦联络人**

有人举报了供应商回扣。警察问你：是公司行为，还是你个人行为？

- ← **承担公司责任**：你把签字都认下来。董事会愿意推你上 CEO，也愿意在需要时推你出去。
- → **交出上级录音**：你打开录音。韩董事长和周启明同时安静下来。

触发：`无`

### ceo_crowning

**董事会秘书**

任命书放在桌上。你从实习生变成 CEO，只差最后一个选择：告诉大家你是谁。

- ← **宣布清账**：你把旧账和整改计划一起发出去。没有掌声，但所有人知道你坐稳了。
- → **宣布增长**：你把数字投到大屏幕上。所有人欢呼，只有你知道最下面那行还没解释。

触发：`无`

## act5

### ceo_first_day

**董事会秘书**

你成为 CEO 的第一天，门口排着三个人：审计、记者，还有一个想要加薪的副手。

- ← **先见审计**：你把会议改名为‘清账会’。顾惟在门外等了两个小时。
- → **先见副手**：你把增长目标交给顾惟。审计只好从门缝里听。

触发：`无`

### ceo_day_two

**你的助理**

第二天，热搜上出现一句话：‘这家公司，谁都不干净。’

- ← **让它挂着**：你没有公关。离职群开始替你筛掉最怕审计的人。
- → **立刻压下去**：你买下所有关键词。舆论消失了，账单和证据都还在。

触发：`无`

## open

### ceo_first_reckoning

**董事会秘书 叶真**

CEO第一晚，叶真把三样东西放到你面前：八万元原单、许棠的故障清单、周启明的聊天记录。  
你先处理哪一件？

- ← **让林岚先看**：你把原件推给审计。第一晚没有掌声，但至少没人能说你删过它。
- → **锁进董事长抽屉**：你把三样东西锁起来。叶真没有阻止你，只在交接表上多写了一行。

触发：`ceo_run and ceo_open=0`

### audit_invitation

**审计负责人**

审计部发来邀请：带上电脑，下午三点聊聊你升职前的那八万元。

- ← **带电脑去**：你打开了所有文件。审计说：至少现在你还在控制叙事。
- → **先找律师**：律师收费很贵，但他提醒你：删文件不是补救。

触发：`ceo_run and turn>=20 and !audit_cooperate`

### audit_witness

**老同事**

那个被你抢过功劳的同事，如今坐在审计桌对面：我可以证明，也可以不证明。

- ← **给他一笔钱**：他收了。你们都知道这不是最后一笔。
- → **请他说实话**：他把报告交上去。你的名声掉了，公司的可信度反而涨了。

触发：`ceo_run and turn>=20`

### audit_ledger

**财务总监**

财务总监找到一本旧账：回扣分给了团队，团队就等于证人。

- ← **让团队补钱**：大家把奖金退回来。你第一次看见共犯也能变成证人。
- → **把责任切给供应商**：你签了一份切割协议。供应商说：我还有你们的聊天记录。

触发：`ceo_run and turn>=20`

### audit_prosecutor

**经侦警官**

警官问：你是来解释账的，还是来交证据的？

- ← **交出上级录音**：录音开始播放。你保住了自由，失去了一整层楼的人。
- → **只解释自己**：你说得很完整。警官也听得很完整。

触发：`ceo_run and turn>=23 and evidence>=4 and !prosecutor_recording`

### board_favor

**董事长**

董事长要你把预算权交给他：‘我只是帮你分担。’

- ← **交预算权**：现金安全了，权力少了一半。董事会开始替你做 CEO 的工作。
- → **送他一笔并购**：他拿到一块没人要的资产，你拿到一票永远的支持。

触发：`ceo_run and turn>=20`

### board_revolt

**聪明副手**

你的副手拿着一份新组织架构：里面没有你的名字。

- ← **给他 COO 头衔**：他留下了。所有人开始先问他，再问你。
- → **把他调去海外**：他走了，顺手把三位客户和一份备份带走。

触发：`ceo_run and turn>=22 and smart_deputy and !deputy_promoted and !deputy_exiled`

### board_vote

**独立董事**

独立董事说：给我一项人事权，我就支持你继续当 CEO。

- ← **给他人事权**：你保住职位，但每个关键岗位都多了一个老板。
- → **给他看证据**：他没有拿到人事权，却成为你最危险的盟友。

触发：`ceo_run and turn>=20`

### team_bonus

**员工代表**

大家知道你拿过回扣。员工代表问：这次奖金，分不分？

- ← **全员分**：所有人都开心了一周。现金只够开心一周。
- → **只奖核心**：核心团队留下，其他人开始在匿名论坛写你的名字。

触发：`ceo_run and turn>=20`

### team_layoff

**人事总监**

订单还没掉，现金先掉了。要不要裁掉那批最早跟你的人？

- ← **裁掉老员工**：报表好看了。离职群里有人发出那张八万元单据。
- → **先降薪**：大家留下，但每个人都记住你说过‘只是暂时’。

触发：`ceo_run and turn>=20`

### team_succession

**老同事**

你要出差三个月。谁替你坐在 CEO 的椅子上？

- ← **让忠诚者代理**：他不出错，也不做决定。公司稳住了，增长停了。
- → **让能干者代理**：他把公司带得更快。回来时，椅子已经有了他的体温。

触发：`ceo_run and turn>=20`

### market_fake

**销售总监**

只差一笔大单，季度增长就能达到董事会目标。客户还没签字。

- ← **先把合同发出去**：客户第二天签了。因为他发现不签就会显得自己落后。
- → **等签字再说**：数字没那么漂亮，但你睡得着。投资人不睡。

触发：`ceo_run and turn>=20`

### market_boom

**客户总监**

订单像洪水一样进来。交付负责人说：再接一单，所有人都会被淹。

- ← **继续接**：市场份额冲上去了。赔偿条款也同时启动。
- → **关掉入口**：你拒绝了增长。客户骂你，老员工第一次鼓掌。

触发：`ceo_run and turn>=20`

### market_competitor

**竞争对手 CEO**
